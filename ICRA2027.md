# ICRA 2027: current Task1–6 evaluation code

Published 2026-09-06 by ql3c20 <2991357552@qq.com>. This branch contains the current local deployment code, including Task1–6 SONIC and TextOp command memos and shared runtime modules. Runtime success/control semantics are preserved. GR00T follows its pre-commit formatting. Existing upstream history is retained; the 2026-09-08 update includes Task1–6 initial-state records and the four HSSD backgrounds with dependencies. Full trajectories, training data, videos, checkpoints, ONNX policy weights, TensorRT engines and environments remain excluded.

## Download

Run in a fresh root directory (the original memos use `/home/ubuntu/yzh`):

```bash
export BASE=/home/ubuntu/yzh
mkdir -p "$BASE"
cd "$BASE"
GIT_LFS_SKIP_SMUDGE=1 git clone -b icra2027 https://github.com/ql3c20/Psi0_kimodo_textop.git
GIT_LFS_SKIP_SMUDGE=1 git -C Psi0_kimodo_textop -c url.https://github.com/.insteadOf=git@github.com: submodule update --init --recursive
GIT_LFS_SKIP_SMUDGE=1 git clone -b icra2027 https://github.com/ql3c20/Isaac-GR00T-rtc.git
mkdir -p HumanoidVLA_MJ_backup
git clone -b icra2027 https://github.com/ql3c20/HumanoidVLA_MJ.git HumanoidVLA_MJ_backup/HumanoidVLA_MJ
```

Authenticate as ql3c20 or an authorized account for the private resource repository. Do not use `submodule update --remote`; keep the pinned commits. `gear_sonic` and `decoupled_wbc` are already SIMPLE submodules. Their source/config files were compared to their pinned GitHub commits before publication.

On a fresh target, attach the model resources to SIMPLE's expected data paths (these are robot assets, not recordings):

```bash
export SIMPLE_ROOT="$BASE/Psi0_kimodo_textop/third_party/SIMPLE"
export HUMANOID_VLA_MJ_ROOT="$BASE/HumanoidVLA_MJ_backup/HumanoidVLA_MJ"
mkdir -p "$SIMPLE_ROOT/data/robots"
test ! -e "$SIMPLE_ROOT/data/robots/g1" && test ! -L "$SIMPLE_ROOT/data/robots/g1" && ln -s "$HUMANOID_VLA_MJ_ROOT/mujoco/model/simple_g1" "$SIMPLE_ROOT/data/robots/g1"
test ! -e "$SIMPLE_ROOT/data/robots/g1_sonic" && test ! -L "$SIMPLE_ROOT/data/robots/g1_sonic" && ln -s "$HUMANOID_VLA_MJ_ROOT/mujoco/model/simple_g1_sonic" "$SIMPLE_ROOT/data/robots/g1_sonic"
```

Existing robot resource directories are intentionally not overwritten. The asset manifest records exact source hashes; XML/OBJ/STL/PNG in the resource repository are scene geometry/materials, not policy weights.

## Included Task1–6 initial states and HSSD scenes

`HumanoidVLA_MJ/mujoco_recordings` contains 751 initial states (Task1: 69; Task2: 167; Task3: 100; Task4: 150; Task5: 126; Task6: 139). Each CSV has a header and one data record; original XML snapshots are included. Point the task recording directory settings to these folders. To retain the original launcher paths on a fresh server, create links without replacing existing data:

```bash
mkdir -p "$BASE/mujoco_recordings"
for task in 20260615_task1_lqb 20260805_task2_lqb 20260804_task3_lqb 20260729_task4_lqb copy/20260825_task5_scq 20260907_task6; do
  if [ ! -e "$BASE/mujoco_recordings/$task" ] && [ ! -L "$BASE/mujoco_recordings/$task" ]; then
    mkdir -p "$(dirname "$BASE/mujoco_recordings/$task")"
    ln -s "$HUMANOID_VLA_MJ_ROOT/mujoco_recordings/$task" "$BASE/mujoco_recordings/$task"
  fi
done
```

HSSD entrypoints in SIMPLE are `data/scenes/hssd/102344280/102344280.usd` (Task1/4) and `data/scenes/hssd/102344250/102344250_local.usd` (Task2/3). Task5 uses `data/scenes/hssd/103997919_171031233/103997919_171031233_local.usd`; Task6 uses `data/scenes/hssd/107734119_175999932/107734119_175999932.usd`. All four scene directories are ordinary Git assets and download with submodule initialization. Published copies repair stale props reference paths; the manifest records changes. Isaac Sim supplies `gltf/pbr.mdl`. File/dependency validation does not establish rendered-image or GPU closed-loop acceptance.

## Validation and limits

- Selected Python syntax and executable wrapper shell syntax passed.
- GR00T `pre-commit run --all-files` passed; 59 selected tests passed in its runtime environment (pytest tooling reused from the SIMPLE environment).
- SIMPLE: 31 focused tests passed, plus the external reset/first-frame test passed after supplying the extracted robot assets: 32 passing tests total.

These tests were preserved, not hidden or used to change evaluation semantics. A full six-file test invocation is therefore not all green.

- No GPU policy server or full closed-loop/100-episode benchmark was run for this publication. No physical robot control was performed.
